# 🌌 CAREERVERSE AI — Next-Gen Cosmic Career Guidance Platform

An AI-powered cosmic ecosystem designed to guide students and professionals through their career journey, academic milestones, and market readiness.

---

## 🚀 Key Modules & Features

- **🪐 3D Career Galaxy**: Interactive Three.js orbital universe featuring 5 planetary career systems, 15+ orbiting specialization moons, and dynamic telemetry cards.
- **🧬 Career DNA Assessment**: Multi-dimensional aptitude and personality scoring algorithm.
- **🔮 Future Predictor**: Market demand analysis, salary scope projections, and 2030 job market growth forecasting.
- **🗺️ Interactive Roadmap Builder**: Stage-by-stage learning roadmaps with progress tracking.
- **🏫 College Explorer & NIRF Matcher**: Comprehensive college database with special focus on premier institutions across India and Karnataka rankings.
- **💬 Gemini AI Career Advisor**: Multi-turn conversational AI counselor with real-time knowledge and contextual guidance.
- **📄 AI Resume Analyzer**: ATS scoring, structural feedback, and instant resume optimization tips.
- **🎓 Entrance Exams & Scholarships**: Curated guides and calendars for national and state-level competitive exams and funding.

---

## 🛠️ Tech Stack

- **Frontend**: Next.js 14, React 18, TypeScript, Tailwind CSS, Three.js, Lucide Icons
- **Backend**: Node.js, Express, TypeScript, MongoDB, Mongoose, JWT Authentication
- **AI Engine**: Google Gemini API (`@google/genai`)
- **Email Service**: Nodemailer / SMTP with instant fallback

---

## 🏁 Getting Started

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- [MongoDB](https://www.mongodb.com/) (Local or Atlas URI)

### 2. Backend Setup
```bash
cd backend
npm install
cp .env.example .env
# Fill in your GEMINI_API_KEY, MONGO_URI, and JWT_SECRET
npm run dev
```

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

Visit `http://localhost:3000` to launch Careerverse AI.
